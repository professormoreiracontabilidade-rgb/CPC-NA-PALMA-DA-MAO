CPC 28 — Propriedade para Investimento

Dicionário pesquisável

ConceitoExplicação
ObjetivoEstabelecer o tratamento contábil e as divulgações aplicáveis às propriedades para investimento.
Propriedade para investimentoTerreno, edifício, parte de edifício ou ambos mantidos para aluguel, valorização do capital ou ambas.
Propriedade ocupadaImóvel usado na produção, fornecimento de bens ou serviços ou para fins administrativos.
Classificação no balançoA propriedade para investimento integra o Ativo Não Circulante, no subgrupo Investimentos.
Terreno para valorizaçãoTerreno mantido para valorização de longo prazo é propriedade para investimento.
Uso futuro indeterminadoTerreno sem uso futuro definido é presumido mantido para valorização.
Edifício alugadoEdifício alugado por arrendamento operacional é propriedade para investimento.
Edifício desocupadoEdifício vazio mantido para futura locação é propriedade para investimento.
Construção futuraImóvel em construção para futura utilização como propriedade para investimento está no alcance do CPC 28.
Imóvel para vendaPropriedade destinada à venda no curso normal do negócio é estoque.
Imóvel ocupado pelo proprietárioÉ tratado pelo CPC 27 ou CPC 06, não pelo CPC 28.
Arrendamento financeiro a terceiroPropriedade arrendada a outra entidade sob arrendamento financeiro não é propriedade para investimento.
Uso misto separávelPartes separáveis são contabilizadas separadamente.
Uso misto inseparávelSó é propriedade para investimento se a parcela ocupada pelo proprietário for insignificante.
Serviços insignificantesServiços de segurança e manutenção podem coexistir com propriedade para investimento.
Serviços significativosHotel administrado pelo proprietário normalmente é propriedade ocupada.
JulgamentoA entidade deve criar critérios consistentes quando a classificação for difícil.
Imóvel alugado ao grupoNas consolidadas é ocupado pelo proprietário; nas individuais pode ser propriedade para investimento.
ReconhecimentoExige benefícios econômicos futuros prováveis e custo mensurável confiavelmente.
Manutenção diáriaÉ reconhecida no resultado.
SubstituiçãoParte substituída pode ser capitalizada e a parte antiga deve ser baixada.
Mensuração inicialA propriedade é inicialmente mensurada pelo custo, incluindo custos de transação.
Custos diretamente atribuíveisIncluem honorários legais, impostos de transferência e outros custos de transação.
Custos excluídosStart-up desnecessário, perdas operacionais iniciais e desperdícios anormais não integram o custo.
Pagamento a prazoO custo é o equivalente à vista; a diferença é despesa financeira.
PermutaUsa valor justo, salvo falta de substância comercial ou mensuração não confiável.
Política contábilA entidade escolhe valor justo ou custo e aplica consistentemente às propriedades.
Valor justoAlterações no valor justo são reconhecidas no resultado do período.
Método do custoSegue CPC 27, CPC 06 ou CPC 31 conforme a situação.
Avaliador independenteÉ incentivado, mas não obrigatório.
Valor justo para divulgaçãoMesmo no método do custo, o valor justo deve ser determinado para divulgação.
Valor justo não confiávelÉ exceção rara e pode levar ao método do custo para aquela propriedade.
TransferênciaSó ocorre quando há alteração efetiva de uso, não mera intenção.
Início de ocupaçãoTransfere de propriedade para investimento para propriedade ocupada.
Desenvolvimento para vendaTransfere de propriedade para investimento para estoque.
Fim de ocupaçãoTransfere de propriedade ocupada para propriedade para investimento.
Início de locaçãoPode transferir estoque para propriedade para investimento.
Venda sem desenvolvimentoPermanece propriedade para investimento até a baixa.
Transferência pelo valor justoO valor justo na data da mudança pode se tornar custo considerado.
AlienaçãoA baixa ocorre na venda ou retirada permanente sem benefícios futuros.
Ganho ou perdaÉ a diferença entre valor líquido da alienação e valor contábil.
IndenizaçãoÉ reconhecida no resultado quando se torna recebível.
DivulgaçãoInclui política, critérios de classificação, valor justo, rendas, gastos, restrições e conciliações.
